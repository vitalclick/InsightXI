# Web app directories

Per the InsightXI frontend structure, this app is organized into:

- `app/` — Next.js App Router routes (present)
- `components/` — reusable UI components
- `modules/` — feature modules (match-intelligence, team-intelligence, ...)
- `services/` — API/data access (present: `api-client.ts`)
- `hooks/` — shared React hooks
- `store/` — Zustand stores (present: `ui-store.ts`)
- `utils/` — pure helpers

Add files to these as features land; this note documents the intended layout.
